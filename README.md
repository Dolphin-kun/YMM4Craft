# YMM4Craft

YMM4（ゆっくりMovieMaker4）で、Minecraft（Java版）の世界をそのまま映像として使えるようにするプラグインと Mod です。
カメラ・時刻・天気・プレイヤーや Mob を YMM4 のタイムラインで動かせるほか、録画したプレイを好きな視点から再生できます。

## 主な機能

- 図形アイテム「YMM4Craftシーン」で、Minecraft の画面をリアルタイムにプレビュー・書き出し
- カメラの位置・向き・視野角、時刻、天気を YMM4 のアニメーションで変更
- プレイヤー・Mob・アイテムをシーンに置き、ポーズエディタで体の各部を動かす
- 背景を消して透過、または好きな色で塗りつぶし
- プレイを録画して、YMM4 で再生（リプレイ）
  - カメラを自由に動かす視点と、録画した人・ほかのプレイヤーの視点
  - 手と持ち物、チェスト・作業台・インベントリの画面、マウスのカーソル、チャットの表示
  - 再生の速さをアニメーションで変更
  - Flashback（`.zip`）・ReplayMod（`.mcpr`）の録画も読み込み
- リプレイの音を WAV に書き出し

## YMM4CraftのMod

- Java版 26.3
- Fabric または NeoForge
- OptionでMod Menu（Fabric のとき）


## インストール

1. YMM4 に、`YMM4Craft` のプラグインを入れてください。
2. Fabric または NeoForge の環境の `mods` フォルダに、その環境用の `ymm4craft-｛バージョン｝.jar` を入れてください（Fabric 用と NeoForge 用は別のファイルです）。

> [!Note]
> YMM4 のプラグインと Mod は、**同じバージョン** をそろえて使ってください。  
> バージョンが合わないときは、YMM4 のワールドの欄と、Minecraft の YMM4Craft の画面にその旨が表示されます。

## 使い方

1. YMM4 で、図形アイテムの「YMM4Craftシーン」を追加すると、YMM4 が Minecraft からの接続を待ち始めます。
2. Minecraft を起動し、タイトル画面の「シングルプレイ」の左にある YMM4 のアイコンを押して、「YMM4と接続」を押します。
   - 同じ画面の「自動で接続」をオンにすると、YMM4 が待っているときにタイトル画面で自動で接続します。
   - 接続している間、Minecraft のウィンドウは隠れます。
3. シーンの「ワールド」の欄で、ワールドを開くか、新しく作るか、リプレイを開きます。
4. 「カメラ」の欄の操作パッドをクリックすると、WASD・Space・Shift とドラッグでカメラを動かせます。

YMM4 のワールドの欄の「切断」を押すと、Minecraft は普段のプレイに戻ります。

## リプレイ

1. Minecraft の YMM4Craft の設定画面で「リプレイを録画する」をオンにします。シングルプレイ・マルチプレイを別々にオン・オフできます。
2. 普段どおりにプレイすると、ゲームのフォルダの `ymm4craft\replays` に録画が保存されます。
3. YMM4 のシーンの「ワールド」の欄で「リプレイを開く」を選びます。

同じ起動構成の `flashback\replays`（Flashback）と `replay_recordings`（ReplayMod）にある録画も、一覧に出ます。

### 音

シーンの「音」の欄の「音を書き出す」で、アイテムの長さぶんの音を WAV に書き出せます。できたファイルの札をタイムラインへドラッグすると、音声アイテムとして置けます。

設定 → 図形 → YMM4Craft の「シーンを読み込んだときに音も書き出す」をオンにすると、プレビューを止めているときに自動で書き出します（保存先を指定しないときは YMM4 の一時フォルダ）。  
そこそこファイルのサイズが大きくなるので、気を付けてください。

## 普段のプレイへの影響について

- Mod は、YMM4 と接続している間だけ動きます。接続していないときは、バニラと同じ動作になります。
- ワールドを開くときは、必ずコピーしたワールドを使います。元のワールドには書き込みません。
- YMM4 との通信は、自分のユーザーだけが使えるフォルダの中で行います。ネットワークのポートは開きません。
- YMM4 が落ちたときは、Minecraft は普段のプレイに戻ります。

## 録画と規約について（重要）

リプレイの録画には、**サーバーから受け取った内容がすべて含まれます**（ほかのプレイヤーの姿や名前、チャットなど）。

1. **参加するサーバーのルールを確認してください。**
   録画や動画の公開を禁止しているサーバーがあります。マルチプレイの録画は、許可されているサーバーだけで行ってください。
2. **ほかのプレイヤーが映る動画を公開するときは、本人の許可を取ってください。**
   チャットやプレイヤー名も録画に入ります。必要に応じて「チャットを表示」をオフにしてください。
3. **録画ファイルの扱い**
   録画ファイルには、受け取ったチャットなどがそのまま保存されます。ほかの人に渡さないでください。

Minecraft の映像を使った動画の公開は、Minecraft の利用規約と[利用ガイドライン](https://www.minecraft.net/ja-jp/usage-guidelines)に従ってください。
